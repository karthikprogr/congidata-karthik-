When you upload CSV/Excel and train a model:

**Step 1: Data Preparation**
- Automatic missing value handling (fillna with mean)
- Categorical encoding (LabelEncoder)
- Train-test split (80/20)

**Step 2: Task Detection**
- Regression: If target has >10 unique values OR is numeric
- Classification: If target has ≤10 unique values OR is categorical

**Step 3: Model Training (ALL models trained automatically)**
For Regression:
  1. LinearRegression
  2. Ridge
  3. RandomForest (100 trees)
  4. GradientBoosting (100 iterations)
  5. DecisionTree

For Classification:
  1. LogisticRegression
  2. RandomForest (100 trees)
  3. GradientBoosting (100 iterations)
  4. DecisionTree

**Step 4: Model Evaluation**
- Regression: R² score (coefficient of determination)
- Classification: Accuracy score

**Step 5: Best Model Selection**
- Automatic leaderboard ranking
- Best model stored for predictions

**Step 6: SHAP Explainability**
- TreeExplainer for tree-based models
- Feature importance with SHAP values
- Interactive Plotly visualizations
