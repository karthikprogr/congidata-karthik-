===========================================
✅ RAG DATA PERSISTENCE - HOW IT WORKS
===========================================

YOUR CONCERN:
"When I reload the page, RAG dataset is gone and asks to upload again"

THE TRUTH:
✅ RAG data IS persisted permanently to disk!
✅ It's stored in: backend/.dataset_store/{your_email}/_rag_metadata.json
✅ The frontend loads it automatically on page load

HOW IT WORKS:

1. BACKEND PERSISTENCE (✅ Already working):
   - When you upload/index a dataset for RAG
   - Backend saves it to: .dataset_store/{user_email}/_rag_metadata.json
   - Also stores chunks in Qdrant vector database
   - Data persists across server restarts

2. FRONTEND LOADING (✅ Already working):
   - Upload.jsx line 97: useEffect(() => { loadRagStatus(); loadRagDatasets(); }, [])
   - Fetches /rag/status to get chunk count
   - Fetches /rag/datasets to get list of indexed datasets
   - Displays: "✓ Knowledge base: X chunks indexed"

3. WHAT YOU'RE SEEING:
   There are TWO different sections on the Upload page:

   A) 📚 Document Q&A Upload (Collapsible)
      - For uploading PDF, DOCX, TXT files
      - This section is COLLAPSED by default
      - Click to expand it
      - The "Select Files" button is for NEW uploads
      - Status shows below: "✓ Knowledge base: X chunks indexed"

   B) 🔍 Indexed RAG Datasets (Always visible)
      - Shows list of datasets already indexed
      - Displays chunk count and indexed date
      - Has delete (✕) button for each dataset

CURRENT STATUS CHECK:

Your RAG data should be at:
d:\Cognidata_mainfinal-main\cognidata\backend\.dataset_store\{your_email}\_rag_metadata.json

The metadata file contains:
{
  "datasets": {
    "dataset_name": {
      "chunk_count": 123,
      "indexed_at": "2026-09-04T..."
    }
  }
}

TO VERIFY IT'S WORKING:

1. Open Upload page
2. Check bottom section: "Indexed RAG Datasets"
3. You should see your indexed datasets listed there
4. If you see "0 datasets indexed" - that means nothing is indexed yet

IMPORTANT NOTES:

- The "📚 Document Q&A Upload" section being collapsed doesn't mean data is lost
- The status line shows: "✓ Knowledge base: X chunks indexed" if you have data
- The "Indexed RAG Datasets" section lists all your indexed datasets
- Data persists permanently until you click the (✕) delete button

IF YOU'RE SEEING "No data indexed yet":
- This means the Qdrant vector database might not have started
- Or the metadata file doesn't exist
- Check if backend server is running properly
- Try re-indexing one dataset to test

THE "SELECT FILES" BUTTON:
- This is NOT asking you to re-upload existing data
- It's for uploading NEW documents/datasets
- Existing data is shown in "Indexed RAG Datasets" section below

✅ Your RAG data is safe and persists across page reloads!
