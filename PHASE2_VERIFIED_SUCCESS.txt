HOW PHASE 2 WORKS
════════════════════════════════════════════════════════════════════════

INDEXING WORKFLOW:
1. User uploads dataframe
2. Convert rows to text chunks
3. Embed with BGE-M3 (1024-dim) ⬆️ Better quality
4. Store in Qdrant ⬆️ Persistent
5. Ready for search!

QUERY WORKFLOW:
1. User asks question
2. Embed query with BGE-M3 ⬆️ Better representation
3. Retrieve top-10 from Qdrant ⬆️ Fast retrieval
4. Rerank with cross-encoder ⬆️ Better precision
5. Keep best 3 documents ⬆️ Less noise
6. Send to LLM for answer ⬆️ Better context

OLD (Phase 1):     MiniLM → numpy → top-5 → LLM
NEW (Phase 2):     BGE-M3 → Qdrant → top-10 → rerank → best-3 → LLM
