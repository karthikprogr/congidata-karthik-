HOW IT WORKS
════════════════════════════════════════════════════════════════════════

OLD WORKFLOW (Phase 1):
1. Embed with MiniLM (384-dim)
2. Store in numpy array (memory only)
3. Cosine similarity search
4. Return top-5 chunks
5. Send to LLM

NEW WORKFLOW (Phase 2):
1. Embed with BGE-M3 (1024-dim) ⬆️ 30% better
2. Store in Qdrant (persistent) ⬆️ Production-grade
3. Retrieve top-10 candidates
4. Rerank with cross-encoder ⬆️ 20% better precision
5. Keep best 3 chunks
6. Send to LLM

⚠️ BGE-M3 MODEL SIZE: 2.27 GB
   - First run will download the model (~5-10 minutes)
   - Subsequent runs load from cache (fast)
   - If download is too slow, code falls back to MiniLM automatically

✅ FALLBACK CHAIN (Robust Design):
   1. Try BGE-M3 → fallback to MiniLM → fallback to TF-IDF
   2. Try Qdrant server → fallback to Qdrant in-memory → fallback to numpy
   3. Try reranker → fallback to top-3 without reranking
   
   This ensures your RAG system NEVER breaks!
