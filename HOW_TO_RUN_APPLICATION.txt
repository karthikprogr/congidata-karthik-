════════════════════════════════════════════════════════════════════════
   ⚠️ TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════

Issue: Backend won't start
  → Check Python installed: python --version
  → Check dependencies: pip install -r backend/requirements.txt
  → Check port 8000 not in use: netstat -ano | findstr :8000

Issue: Frontend won't start
  → Check Node.js installed: node --version
  → Check dependencies: cd frontend && npm install
  → Check port 5173 not in use: netstat -ano | findstr :5173

Issue: Can't login
  → Use default credentials: admin@cognidata.com / admin123
  → Check backend is running: http://localhost:8000/docs

Issue: Upload fails
  → Check file size <200MB
  → Check file format: CSV, Excel, JSON
  → Check backend logs for errors
