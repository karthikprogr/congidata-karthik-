   🔄 HOW AUTOML WORKS (Initialization Flow)
════════════════════════════════════════════════════════════════════════

1️⃣ USER UPLOADS DATASET
   ↓
   Dataset stored in pandas DataFrame

2️⃣ USER CALLS run_automl(df, target_column)
   ↓
   Function: run_automl(df, target, user_id, hyperparameter_tuning)

3️⃣ TASK DETECTION (Automatic)
   ↓
   def _detect_task(y):
       if y.dtype == object OR y.nunique() <= 10:
           return "classification"    # Categorical target
       else:
           return "regression"        # Numerical target
   
   Example:
   • Target = "price" (continuous) → REGRESSION
   • Target = "category" (A/B/C) → CLASSIFICATION
   • Target = "churn" (0/1) → CLASSIFICATION

4️⃣ DATA PREPARATION
   ↓
   def _prepare(df, target):
       - Drop rows with missing target
       - Encode categorical features (LabelEncoder)
       - Split features (X) and target (y)
       - Fill missing values with mean
       - Split 80/20 train/test
   
   Result: X_train, X_test, y_train, y_test

5️⃣ MODEL SELECTION (Based on Task)
   ↓
   if task == "regression":
       models = REGRESSION_MODELS (8 models)
   else:
       models = CLASSIFICATION_MODELS (7 models)

6️⃣ OPTIONAL: HYPERPARAMETER TUNING
   ↓
   if hyperparameter_tuning == True:
       For XGBoost, LightGBM, CatBoost:
           best_params = optimize_hyperparameters(X, y, model_name)
           → Optuna runs 20 trials
           → Bayesian optimization
           → Finds best: n_estimators, max_depth, learning_rate, subsample
           → Creates new model with optimized params

7️⃣ TRAIN ALL MODELS (Parallel)
   ↓
   for name, model in models.items():
       1. Fit model: model.fit(X_train, y_train)
       2. Predict: preds = model.predict(X_test)
       3. Compute metrics:
          
          REGRESSION:
            • R² (primary metric for ranking)
            • RMSE (root mean squared error)
            • MAE (mean absolute error)
            • MSE (mean squared error)
          
          CLASSIFICATION:
            • Accuracy (primary metric for ranking)
            • F1 Score (weighted average)
            • ROC-AUC (if binary classification)
       
       4. Store result: {name, score, model, metrics}

8️⃣ RANK MODELS (Sort by Primary Metric)
   ↓
   • Regression: Sort by R² (descending, higher better)
   • Classification: Sort by Accuracy (descending, higher better)
   
   Example Leaderboard:
   1. XGBoost        → R²=0.89, RMSE=12.3, MAE=9.1
   2. LightGBM       → R²=0.87, RMSE=13.1, MAE=9.8
   3. CatBoost       → R²=0.86, RMSE=13.5, MAE=10.2
   4. RandomForest   → R²=0.82, RMSE=15.2, MAE=11.5
   5. ...

9️⃣ SELECT BEST MODEL
   ↓
   best_model = max(results, key=lambda r: r['score'])

🔟 STORE IN MEMORY (Per-User)
   ↓
   _models[user_id] = {
       "model": best_model,
       "feature_cols": ['age', 'income', 'credit_score', ...],
       "target": "loan_approved",
       "task": "classification",
       "score": 0.89,
       "metric": "Accuracy"
   }

1️⃣1️⃣ RETURN RESULTS
   ↓
   {
       "best_model": "XGBoost",
       "task": "regression",
       "score": 0.89,
       "leaderboard": [
           {"model": "XGBoost", "R²": 0.89, "RMSE": 12.3, "MAE": 9.1},
           {"model": "LightGBM", "R²": 0.87, ...},
           ...
       ],
       "features": ['age', 'income', ...],
       "train_rows": 800,
       "test_rows": 200
   }

════════════════════════════════════════════════════════════════════════
   🎯 WHY THIS INITIALIZATION STRATEGY?
════════════════════════════════════════════════════════════════════════

✅ MODEL COMPETITION (Not Single Model)
   • Trains ALL models in parallel
   • Picks best performer automatically
   • User doesn't need to choose
   • Always gets best results

✅ HYBRID APPROACH (Old + New)
   • Keep sklearn models (baseline, robust)
   • Add XGBoost/LightGBM/CatBoost (best accuracy)
   • Best of both worlds

✅ DEFAULT PARAMETERS (Smart Choices)
   • n_estimators=100 (balance speed/accuracy)
   • random_state=42 (reproducible)
   • verbosity=0 (silent training)
   • max_depth=6 for trees (prevent overfitting)

✅ AUTOMATIC TASK DETECTION
   • User doesn't specify regression/classification
   • Algorithm decides based on target type
   • Foolproof

✅ COMPREHENSIVE METRICS
   • Not just accuracy/R²
   • Includes RMSE, MAE, F1, ROC-AUC
   • Full picture of performance

✅ IN-MEMORY STORAGE
   • Fast access (no disk I/O)
   • Per-user isolation
   • Ready for predictions
